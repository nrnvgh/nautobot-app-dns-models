# DNSRuleRecord Model

*Placeholder documentation for GUI DNS Rule Record tracking model.*

## Overview

The `DNSRuleRecord` model tracks which GUI-based DNS rules generated which DNS records from which source objects.

## Purpose

- Enables cleanup when rules change
- Provides audit trail of generated records  
- Supports cascade deletion when source objects are removed
- Allows bulk operations on rule-generated records
